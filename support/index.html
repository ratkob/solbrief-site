SolBrief Support

Need help with your SolBrief Pro subscription, municipal event verification, or the Explain This Letter tool?

  • Support Email: support@ratko.biz
  • Restore Purchases: Open SolBrief → Tools or Paywall → tap Restore Purchases.
  • Manage or Cancel Subscription: Open SolBrief → Tools → tap Manage Subscription (opens Apple ID Subscriptions) or visit apps.apple.com/account/subscriptions.
  • Report a Factual Correction: Tap Report an error at the bottom of any brief or event card.
